# One aggregated entity for integrations that fail to load

All integrations that fail to load are reported through a single entity whose state is the Problem Level while any integration is failing and whose attributes list the failing integrations; the dashboard shows it as one Notice ("2 integrations not loading: Nibe, Tibber"). We rejected one entity per integration, because most households have 50+ integrations and nearly all of those entities would sit Hidden forever, and creating and removing entities as integrations break, because Home Assistant handles disappearing entities poorly and third-party cards would lose a stable ID. The cost is that the aggregate is snoozed as a whole; a newly failing integration counts as a New occurrence so it is not silently swallowed by an earlier snooze.
